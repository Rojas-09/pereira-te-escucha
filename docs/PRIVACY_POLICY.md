# Politica de Privacidad - Pereira Te Escucha

Ultima actualizacion: 2026-04-07

## 1. Quienes somos

Pereira Te Escucha es una aplicacion para radicar solicitudes ciudadanas (PQRSD) y dar seguimiento al estado del caso.

## 2. Datos que tratamos

La aplicacion puede tratar los siguientes datos, segun lo que el usuario diligencie:

- Datos de la solicitud: tipo de solicitud, asunto y descripcion.
- Datos de contacto opcionales: correo electronico (cuando el medio de respuesta lo requiere).
- Ubicacion aproximada o precisa: solo cuando el usuario la autoriza para ubicar el caso en el mapa.
- Archivos adjuntos: fotos o documentos que el usuario decide anexar como evidencia.
- Datos tecnicos minimos: logs tecnicos para diagnostico de errores y seguridad del servicio.

## 3. Finalidad del tratamiento

Usamos los datos para:

- Radicar la solicitud ciudadana ante los canales institucionales definidos.
- Dar trazabilidad y permitir seguimiento del estado.
- Prevenir abuso del servicio (seguridad, rate limiting y validaciones).
- Resolver incidentes tecnicos y mejorar la estabilidad de la plataforma.

## 4. Base de legitimacion y consentimiento

El tratamiento se realiza con base en:

- El consentimiento del usuario al enviar la solicitud y aceptar el tratamiento.
- El cumplimiento de finalidades de interes publico asociadas a atencion ciudadana.

## 5. Comparticion de datos

Los datos pueden compartirse con:

- Plataformas o servicios oficiales de recepcion de PQRSD.
- Proveedores tecnicos necesarios para operar la plataforma (hosting, base de datos, monitoreo), bajo obligaciones de confidencialidad.

No vendemos datos personales a terceros.

## 6. Retencion de datos

Conservamos la informacion solo durante el tiempo necesario para:

- Gestionar la solicitud.
- Cumplir obligaciones legales o regulatorias.
- Atender auditorias o requerimientos de autoridad competente.

## 7. Seguridad

Aplicamos medidas razonables de seguridad, incluyendo validacion de entrada, controles de acceso y monitoreo tecnico.

## 8. Derechos del titular

El usuario puede solicitar acceso, actualizacion, rectificacion o supresion de sus datos conforme a la normativa aplicable.

Para ejercer sus derechos, use el canal de contacto oficial de la entidad responsable del servicio.

## 9. Permisos de la aplicacion

- Ubicacion: para registrar la posicion del reporte cuando el usuario lo permite.
- Camara/galeria: para adjuntar evidencias al reporte.

Estos permisos se usan unicamente para las funcionalidades descritas.

## 10. Menores de edad

La aplicacion no esta orientada especificamente a menores de edad. Si se detecta tratamiento no autorizado de datos de menores, se tomaran medidas correctivas.

## 11. Cambios a esta politica

Podemos actualizar esta politica para reflejar cambios legales, tecnicos u operativos. La version vigente estara disponible en la URL publica definida para la app.

## 12. Contacto

Para temas de privacidad y tratamiento de datos, utilice el canal oficial de atencion de la entidad responsable del servicio.
