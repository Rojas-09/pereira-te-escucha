Política de Privacidad

Última actualización: Abril 2026

Esta aplicación móvil, Pereira Te Escucha, es mantenida por Juan Andrés Rojas como parte de un proyecto académico de la Universidad Tecnológica de Pereira.

1. Datos que recopilamos

  • Datos de la solicitud: tipo de PQRSD, asunto y descripción.
  • Datos de contacto opcionales: correo electrónico (cuando el medio de respuesta lo requiere).
  • Ubicación: coordenadas del punto del reporte, solo cuando el usuario autoriza y selecciona una ubicación.
  • Archivos adjuntos: fotos o documentos que el usuario decida anexar como evidencia.
  • Datos técnicos mínimos: logs para diagnóstico de errores y seguridad del servicio.

2. Finalidad del tratamiento

Usamos los datos para:

  • Radicar la solicitud ciudadana ante los canales institucionales definidos.
  • Dar trazabilidad y permitir seguimiento del estado.
  • Prevenir abuso del servicio (seguridad, rate limiting y validaciones).
  • Resolver incidentes técnicos y mejorar la estabilidad de la plataforma.

3. Base de legitimación y consentimiento

El tratamiento se realiza con base en:

  • El consentimiento del usuario al enviar la solicitud y aceptar el tratamiento de datos.
  • El cumplimiento de finalidades de interés público asociadas a atención ciudadana.

4. Compartición de datos

Los datos pueden compartirse con:

  • Plataformas o servicios oficiales de recepción de PQRSD.
  • Proveedores técnicos necesarios para operar la plataforma (hosting, base de datos, monitoreo), bajo obligaciones de confidencialidad.

No vendemos datos personales a terceros.

5. Retención de datos

Conservamos la información solo durante el tiempo necesario para gestionar la solicitud, cumplir obligaciones legales y atender auditorías o requerimientos de autoridad competente.

6. Seguridad

Aplicamos medidas razonables de seguridad, incluyendo validación de entrada, encriptación en tránsito (HTTPS), controles de acceso mediante tokens API y monitoreo técnico.

7. Derechos del usuario

El usuario puede solicitar acceso, actualización, rectificación o supresión de sus datos conforme a la normativa aplicable. Para ejercer sus derechos, contacta a: juan.rojas7@utp.edu.co.

8. Permisos de la aplicación

  • Ubicación: para registrar la posición del reporte cuando el usuario lo permite.
  • Cámara/galería: para adjuntar evidencias al reporte.

Estos permisos se usan únicamente para las funcionalidades descritas.

9. Menores de edad

La aplicación no está orientada específicamente a menores de edad. Si se detecta tratamiento no autorizado de datos de menores, se tomarán medidas correctivas.

10. Cambios a esta política

Podemos actualizar esta política para reflejar cambios legales, técnicos u operativos. La versión vigente estará disponible en esta URL.
